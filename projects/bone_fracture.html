Problem & Impact

Manual fracture assessment is time-sensitive and prone to variability. During surgery, angle misestimation can impact fixation outcomes. This system augments radiologists and surgeons with instant, quantitative insights, improving consistency and efficiency across the workflow.

  • Clinical relevance: Quantitative geometry for precision-driven surgeries.
  • Speed: AI-assisted detection within seconds.
  • Accessibility: Runs on modest GPUs or cloud endpoints.
  • Scalability: Extensible to different bones and pediatric use-cases.

System Architecture

High-level flow: Input X-ray → Preprocess → YOLOv8 Detection (fracture, fragments, tools) → Postprocess → Angle Estimation → Output Overlays & Metrics

Model

  • YOLOv8 (PyTorch) for object detection
  • Custom anchors & tuned hyperparameters
  • Augmentations: rotate/scale/blur/noise

Angle Estimation

  • Keypoint/line extraction (OpenCV)
  • Vector geometry & robust thresholding
  • Overlay rendering with sub-degree precision

Dataset & Annotations

Trained and validated on a curated medical imaging set with fractured and non-fractured X-rays. Annotations available in YOLO, COCO, PASCAL VOC, and VGG JSON formats. Balanced splits for train/val/test.

Training & Evaluation

Model Comparison & Results

We evaluated multiple YOLOv8 variants (n, s, m) on the annotated FracAtlas dataset. Among them, YOLOv8s delivered the best trade-off between speed and accuracy.

YOLOv8s Performance Metrics

  • Precision: 0.61
  • Recall: 0.50
  • mAP@50: 0.47
  • mAP@50–95: 0.24
  • Inference Speed: ~14.8 ms/image

These results establish YOLOv8s as the most efficient and accurate model for real-time bone fracture detection.

Angle Estimation (OpenCV)

import cv2, numpy as np
def angle_between(p1, p2, p3):
    v1 = np.array(p1) - np.array(p2)
    v2 = np.array(p3) - np.array(p2)
    cosang = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2) + 1e-8)
    return np.degrees(np.arccos(np.clip(cosang, -1, 1)))
